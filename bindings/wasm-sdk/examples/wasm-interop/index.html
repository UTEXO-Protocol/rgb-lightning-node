RLN WASM Interop Examples

These examples are automated, end-to-end RGB-over-Lightning flows that run headless against a native rgb-native-phase5-node peer. They are driven from Node (not opened directly in a browser) — each driver boots the native node(s), serves this directory, launches headless Chrome via puppeteer-core, runs the in-browser flow, and asserts success.

Flows

  • Full RGB-over-Lightning flow — run_e2e_full_flow.mjs (page rgb_e2e_full_flow.html + manual_js_rgb_e2e_full_flow.js): vanilla + RGB channels, real BTC/BOLT11/HODL/RGB payments both directions, keysend, close, and persistence-restore verify.
  • Multi-hop forwarding — run_multihop_flow.mjs (page rgb_multihop_flow.html + manual_js_rgb_multihop_flow.js): native-A → WASM → native-B (boots two native nodes).

Run

Prereqs: compose.wasm.yaml infra running, the wasm pkg/ built, and the rgb-native-phase5-node harness binary available. See README.md for full instructions. Example: 

PUPPETEER_EXECUTABLE_PATH=/usr/bin/google-chrome \
E2E_PUPPETEER=/tmp/e2e-driver/node_modules/puppeteer-core \
node bindings/wasm-sdk/examples/wasm-interop/run_e2e_full_flow.mjs
