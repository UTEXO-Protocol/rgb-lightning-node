RLN WASM Real RGB Channel Flow

Demonstrates the WasmRgbBackend channel flow: wallet attach → fund on-chain → issue NIA asset → open real RGB channel to rgb-native-phase5-node → keysend → cooperative close.

Requires: Esplora (3002) · RGB proxy server (3000) · WASM proxy gateway (3001) · rgb-native-phase5-node (19735/19737). Start infra with docker compose -f compose.wasm.yaml up and the native node binary from contrib/rgb-cross-variant-harness.
