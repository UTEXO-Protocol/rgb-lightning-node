RLN WASM Virtual Channel SDK Flow

Runs the same high-level sequence as the Python virtual-channel SDK example: init/unlock, connect peers, open `trusted_no_broadcast` virtual channel, keysend A->B, keysend B->A, close channel (with host/fallback close retry).

Note: this is the wasm runtime flow, so settlement statuses are driven via wasm status APIs/events instead of native LDK daemon callbacks.

Optional: set relay auth values below if your proxy requires auth. If left empty, the flow tries window.getRelaySessionAuth(...).
