WASM ↔ utexo-lsp — Async Payments with LSP (two recipients + payment)

Two independent wasm nodes each open a vanilla channel to a native invoice-host node → apayNewWithAddress (register a signed 200-hash batch + Lightning-Address attestation) → apayNew refill & assert the persisted hash cursor advanced → node B resolves node A's Lightning Address via LNURL-pay and pays it; A's backend answers the host's request_invoice and auto-claims, settling B's payment end-to-end. Requires compose.wasm.yaml infra, a native invoice-host node started with --lsp-base-url, and utexo-lsp running. Driven headlessly by run_apay_lsp_flow.mjs (auto-runs when ?phase= is present).
