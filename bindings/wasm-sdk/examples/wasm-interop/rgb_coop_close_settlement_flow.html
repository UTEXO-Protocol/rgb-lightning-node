Cooperative Close — On-Chain RGB Settlement on the WASM Side

The native hub opens a real, on-chain-funded, anchors RGB channel to this wasm node with push_asset_amount, one RGB keysend lands hub→wasm, then the wasm side cooperatively closes the channel. The flow then asserts that the wasm side's RGB share of the colored closing transaction settles into the on-chain wallet (getAssetBalance > 0) — the bug under test is that it stays 0 forever because the wasm backend never drains ChainMonitor events, never handles SpendableOutputs, and has no colored sweep pipeline. Requires compose.wasm-infra.yaml infra, the wasm-proxy-gateway (dev-http), and a fresh native rgb-lightning-node (peer 9802, REST 3101). Driven headlessly by run_coop_close_settlement_flow.mjs (auto-runs when ?autorun is present).
